# Support

GuardWSL is pre-release software maintained on a best-effort basis.

- Read [`README.md`](README.md), [`docs/INSTALLATION.md`](docs/INSTALLATION.md),
  and [`docs/SAFETY.md`](docs/SAFETY.md) first.
- Run `guard doctor`, `guard status`, and `guard clean --dry-run` before asking
  for help. Remove private paths and machine details from shared output.
- Use the question issue template for usage help and the bug template for a
  reproducible defect.
- Report vulnerabilities privately according to [`SECURITY.md`](SECURITY.md).

Never attach credentials, SSH keys, complete environment dumps, private source
code, or an unredacted audit log to a public issue.
